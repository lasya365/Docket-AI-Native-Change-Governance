# Docket — AI-Native Change Governance

## Overview

**Docket** is a prototype exploring how **Freshservice Change Management** can evolve alongside the **AI Development Lifecycle (ADLC)**.

As software development moves from the traditional **Software Development Lifecycle (SDLC)** toward AI-assisted development, AI coding agents introduce additional context around software changes.

Docket explores how this context — including **AI intent, session context, change impact, risk signals, and governance information** — can complement the existing change-management workflow.

## What Docket Demonstrates

Docket demonstrates an AI-aware change-management experience built around:

* **AI Intent** — what the AI agent was asked to accomplish.
* **AI Session Context** — the interaction that resulted in the change.
* **Change Impact** — the files, components, or services affected.
* **Risk Signals** — factors that help indicate potential impact.
* **Governance Context** — information that can support review and approval decisions.
* **Traceability** — connecting AI activity with the resulting change.

The goal is to complement existing **Freshservice Change Management** capabilities as organizations adopt AI-assisted development.

## SDLC to ADLC

Traditional software development follows the **Software Development Lifecycle (SDLC)**, with established processes for development, review, testing, approval, and deployment.

As AI coding agents become active participants in development, organizations are moving toward an **AI Development Lifecycle (ADLC)**.

Docket explores how existing change-management practices can evolve with this shift by bringing AI-specific context into the change workflow.

## How to Run

1. Clone or download this repository.
2. Open `docket-prototype.html` in a modern web browser.
3. Interact with the Change Management workflow.
4. Explore the AI-native context, intent, session information, impact, risk, and governance details.
5. Follow the recommended workflow to explore an AI-generated change.

No installation, dependencies, or backend setup are required for the prototype.

## Recommended Demo Flow

For the best experience:

1. Open the **Changes** section.
2. Explore the existing change-management workflow.
3. Open an AI-generated change scenario.
4. Review the **AI intent and session context**.
5. Examine the **change impact and risk signals**.
6. Review the available governance and review information.
7. Observe how the AI-native context complements the existing change record.
